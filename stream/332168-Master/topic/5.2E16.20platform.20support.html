@Dave Register : Will 5.16 for Android still use wxw 3.0?

5.16 is planned to be released end of March/beginning of April -27. Currently envisioned platform support:

  1. Windows: win64 for x86_64. That is, no 32bits builds
  2. Debian: 13/Trixie and 12/Bookworm . Version 14/Forky will land in summer/autumn -27 at which point we should release 5.16 for it. All released for arm64 and amd64
  3. Ubuntu: 22.04 Jammy, 24.04 noble and 26.04 resolute. There will no more LTS releases before 5.18.
  4. Flatpak: Runtime 26.08 for arm64 and x86_64
  5. MacOS. Universal builds targeting 10.10
  6. Android: 32-bit and 64 bit builds , 32-bits still mandated by Google (?).

All platform uses wxWidgets 3.2 except:

- Windows (win64) uses 3.3 or, if available when released, 3.4.
- Android uses 3.0.

Overall update to wxWidgets 3.4 is planned for 5.18.
