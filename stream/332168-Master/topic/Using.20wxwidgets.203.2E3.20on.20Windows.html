Topic: Using wxwidgets 3.3 on Windows

Alec Leamas (Oct 12 2026 at 07:06):

@Dave Register @Pavel Kalian

We should IMHO make some decision: should we use wx 3.3 for 5.16 windows builds or not?

There are good arguments for using 3.3 on Windows. I'm particularly concerned about all menu colour stuff like #5466 which will have a new context when we move to 3.3 and the related windows dark mode. It would also mean much more common code paths for this stuff which has annoying details.

There is also a question about the wisdom about releasing win64 using wxw 3.2, just to replace it with 3.3/3.4 months later. Perhaps better to jump on 3.3 directly for at least win64?

That said, moving to 3.3 will affect plugins, obscure compilation errors typically when plugins tries to iterate over API wxList lists.
It seems that the wxList 3.3 incompatibilities basically are about how the plugins use the API, not the API as such.

Thoughts?
