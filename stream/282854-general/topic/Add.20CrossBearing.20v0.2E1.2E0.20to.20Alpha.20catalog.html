Hi all,

After a lot of help I hope I've managed to add CrossBearing v0.1.0 to the OpenCPN Alpha plugin catalog for initial community testing. Please let me know if I've mucked anything up.

CrossBearing takes position fixes from cross bearings on charted objects and waypoints, without GPS. It is useful when GNSS is unavailable or unreliable. Source: https://github.com/g0kad/crossbearing_pi. Discussion: #1440.

Platforms included:

  • Debian 12 (bookworm): x86_64, arm64 (tested)
  • Debian 13 (trixie): x86_64, arm64
  • Flatpak 24.08: x86_64, aarch64
  • Windows: msvc-wx32 (32-bit) (tested) and msvc-64 (for the upcoming 64-bit OpenCPN)
  • macOS universal: arm64 + x86_64

Tarballs are hosted in the opencpn/crossbearing-prod Cloudsmith repository. All nine metadata files pass ocpn-plugins.xsd, and each tarball downloads and matches its tarball-checksum. Testers on Cruisers Forum have run the alpha build on Windows 11.

If any other platform turns out not to work, I'll withdraw that file.
