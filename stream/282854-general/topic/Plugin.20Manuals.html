Alec Leamas (Nov 16 2026 at 09:17):

It's a decentralized approach basically in the hands of each plugin dev. Bits and pieces:

  1. All included plugins are listed in https://github.com/opencpn-manuals/main/blob/main/site.yml. If a new plugin should be added, please make a PR against https://github.com/opencpn-manuals/main/
  2. Plugin devs updates their sources for the manual.
  3. The manual is rebuilt regularly, at least daily. This makes the new manual visible.
  4. In order to get a usable turn around, it is important to establish a local build chain using antora. This is basically about getting antora to work , see https://docs.antora.org/antora/3.0/install/install-antora/. This way the results can be checked without having to wait for the complete manual to be rebuilt
